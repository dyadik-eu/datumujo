# Code of conduct

This project is a place for technical work. Everyone who takes part
treats the others with respect.

- Discuss the change, not the person.
- Harassment, insults and discrimination are not accepted, in any form.
- Private information of others is not published.

The maintainer removes comments, commits or issues that break these rules
and can block a person from the project.

Report a problem in private to ludwig@ludwigjmarx.dev. The report stays
confidential.
